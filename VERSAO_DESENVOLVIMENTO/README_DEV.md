# 🛠️ INNOVCORE TI - Ambiente de Desenvolvimento & Testes

Esta pasta contém o histórico de desenvolvimento, amostras de testes e backups de segurança do projeto **InnovCore TI**.

---

## 📁 Estrutura da Pasta de Desenvolvimento

- **`Backups/`**: Backups automáticos de segurança gerados a cada exclusão ou alteração de equipamentos na base.
- **`TESTES_E_EXEMPLOS/`**:
  - `inventario_geral_innovtech_EXEMPLO.csv`: Amostra de planilha de inventário com múltiplos computadores.
  - `inventario_innovtech_hibrido.bat`: Script híbrido legado utilizado nas versões preliminares.
  - `Inventario_InnovTech_Exemplos/`: Modelos e relatórios exportados de exemplo.

---

*Nota: Para utilizar o sistema em campo ou gravar em Pen Drive, utilize exclusivamente a pasta `VERSAO_FINAL`.*
